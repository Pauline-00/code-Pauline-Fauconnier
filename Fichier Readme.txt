Description du projet :
Ce projet consiste a créer un jeu éducatif pour les élèves afin qu'ils puissent réviser les mathématiques de façon autonome.

Les instructions d’installation et d’utilisation : 
Il faut avoir un compilateur C installé. Télécharger les fichiers du projet. Il suffit ensuite de suivre les indications du menu du code.

Les prérequis et outils utilisés :
il faut avoir des connaissances en langage C. Les outils utilisés sont le langage C, un compilateur.
